# Album musicali

Aprire `AlbumMusicali.csproj` con Visual Studio 2026, con il carico di lavoro **Sviluppo di applicazioni desktop .NET**, e avviare il progetto. È richiesto .NET 10.

Selezionare una categoria e premere **Visualizza album**. Il pulsante **Calcola statistiche** mostra l'album più vecchio e la durata media degli album visualizzati. Selezionando una riga si vedono i brani dell'album nella seconda griglia.

I dati di esempio sono nel codice e non vengono salvati su file.
